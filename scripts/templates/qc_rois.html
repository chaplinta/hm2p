Signal quality by predicted class

Calcium QC metric

One dot per ROI (ca.h5 roi_qc, computed in stage 4 by hm2p.calcium.qc.compute_roi_qc), grouped by predicted class; diamond: selected ROI; dashed lines: the display thresholds in hm2p.calcium.qc, the same ones the ROI viewer page of the Streamlit app uses (event SNR ≥ 3, decay τ 0.2–4 s, Spearman correlation of dF/F with the mean neuropil ≤ 0.6, bleaching slope ≥ −0.4, i.e. less than 40 % loss, active fraction ≥ 0.05). An ROI outside a threshold is flagged, not removed; a missing value (e.g. decay τ with fewer than 3 events) does not count as a failure.

Rigid registration offsets and correlation with the reference

ops.npy xoff / yoff: rigid shift applied to each frame (px); corrXY: peak phase correlation of the frame with the reference image. Abrupt steps in the shift or drops in corrXY mark movement the registration may not have corrected.

How to read this

  • The reference accuracy is computed by refitting the classifier once per held-out legacy session with the champion's training recipe (same hyper-parameters, softmax objective, balanced class weights; missing features filled with training-fold medians) (stricter than the single random 80/20 split behind the stored test F1, which shares sessions between training and test). It is computed from the legacy Suite2p runs with manual soma and dendrite labels in /data/s2p.
  • Acceptance criteria in docs/soma-classifier.md: macro F1 ≥ 0.85, every class F1 ≥ 0.7, and fewer than 5 % of true artefacts labelled soma.
  • Manual labels mark only the cells a person accepted; everything else is "artefact", so some real but dim cells are counted as artefacts in the reference.

Cloud-based analysis pipeline for two-photon calcium imaging of head

1. PROJECT DESCRIPTION

Problem Statement

Head direction (HD) cells in the retrosplenial cortex (RSP) maintain an
internal representation of the animal's facing direction, but how
genetically distinct RSP populations (Penk+ vs Penk-CamKII+) contribute
to this representation — and whether they differ in their reliance on
visual vs path-integration cues — remains unknown. Answering this
question requires processing large-scale two-photon calcium imaging
datasets (>100 GB) from freely moving mice alongside synchronised
behavioural video tracking. The computational demands of motion
correction, cell detection, pose estimation, and spike inference exceed
what is feasible on a single workstation and require GPU-accelerated
cloud computing.

Project Summary

This project serves a dual purpose. The primary scientific goal is to
analyse head direction coding in RSP using two-photon calcium imaging
from 26 sessions (20 animals, ~113 GB). But it is also an experiment in
AI-assisted science: the entire analysis pipeline — code, tests,
documentation, infrastructure, and frontend — was built collaboratively
with an AI coding agent (Claude Code, Anthropic). The pipeline
comprises 5,600+ lines of processing code, 1,500+ unit tests at 91%+
coverage, and a 53-page interactive frontend, developed in weeks rather
than the months this would typically require.

This approach points toward a future where AI agents build and maintain
scientific analysis pipelines, generate testable hypotheses from data,
and iteratively refine analyses based on results — with the scientist
directing the research questions and interpreting the findings. This
project is an early demonstration of that workflow applied to systems
neuroscience. The AI-built pipeline also advances reproducibility: every
processing step is version-controlled, unit-tested, containerised in
Docker, and orchestrated by Snakemake, making the entire analysis
re-runnable from raw data to final figures on any machine with AWS
access. The full commit history documenting the AI-assisted development
process is publicly visible at https://github.com/chaplinta/hm2p.

The pipeline extracts neural activity (Suite2p), tracks animal pose
(DeepLabCut), computes behavioural kinematics (head direction, speed,
position), and aligns neural and behavioural data for downstream
analysis of HD tuning, population decoding, and visual cue dependence.
It is implemented in Python, orchestrated by Snakemake, and runs on AWS
EC2 instances with data stored on S3. All code is open-source
(https://github.com/chaplinta/hm2p).

AWS Services Used

  EC2 (g4dn.xlarge, Spot) — GPU-accelerated calcium extraction
  (Suite2p), pose estimation (DeepLabCut), spike inference (CASCADE),
  model fine-tuning

  EC2 (c5.xlarge, Spot) — CPU stages: kinematics, calcium processing,
  sync, analysis, behavioural syllable extraction (keypoint-MoSeq)

  S3 (Standard + Intelligent-Tiering) — Raw data storage (two-photon
  TIFF stacks, behavioural video, DAQ files) and pipeline derivatives
  (extracted signals, pose estimates, synchronised datasets, analysis
  results)

  CloudWatch (Basic) — Pipeline monitoring and logging

Cost Breakdown

  S3 storage (~200 GB, 12 months)                            $60
  EC2 GPU g4dn.xlarge Spot (Suite2p 52h, DLC 156h,
    CASCADE 2h, DLC fine-tuning 24h)                         $37
  EC2 CPU c5.xlarge Spot (kinematics, calcium, sync,
    analysis, MoSeq ~10h)                                     $1
  Data transfer (S3 egress)                                  $10
  Subtotal (current dataset, single pass)                   $108

  DLC fine-tuning iterations — the SuperAnimal pretrained
    model requires iterative fine-tuning on manually labeled
    frames specific to this experimental setup (overhead
    view, 2P headstage occluding bodyparts, maze walls).
    Each round: label 50-100 frames, train on GPU (~24h),
    evaluate, re-label problem frames. Expect 5-10 rounds
    to achieve reliable tracking across all sessions.
    (5-10 rounds x 24h GPU x $0.16/h Spot)                 $400

  CASCADE spike inference — calibrated deep-learning spike
    rate estimation requires GPU. Must re-run after each
    calcium processing update.
    (26 sessions x multiple re-runs)                        $100

  Alternative pose estimation models — evaluating SLEAP
    and AnimalPose alongside DeepLabCut to determine the
    best tracker for this preparation. Each requires GPU
    training and inference across 26 sessions.              $300

  CEBRA contrastive embeddings — GPU-accelerated joint
    neural-behavioural embedding (Schneider et al. 2023).
    Multiple hyperparameter configurations and
    cross-validation folds.                                 $300

  NEMOS GLM encoding models — parameter sweeps across
    HD, speed, AHV, acceleration, and position regressors
    to control for movement confounds
    (Zagha et al. 2022).                                    $200

  keypoint-MoSeq behavioural syllable extraction —
    zero-label AR-HMM segmentation (Weinreb et al. 2024).
    Must re-run after each DLC update. Multiple kappa
    values for model selection.                             $100

  Pipeline re-runs — full Stage 1-6 re-processing after
    each DLC, Suite2p, or pose tracker change. Each full
    re-run: ~80h GPU + downstream CPU stages.
    (5-8 full re-runs expected across tracker/parameter
    comparisons)                                            $600

  Future recordings — 20-40 additional sessions from
    new animal cohorts with optogenetic manipulation
    of Penk+ cells. Full pipeline processing per cohort.    $800

  Extended storage — S3 growth to ~500 GB with additional
    sessions, model checkpoints, and NWB exports.
    12 months at Intelligent-Tiering.                       $150

  Streamlit frontend hosting on EC2 for collaborator
    access during manuscript preparation and review.        $200

  Contingency — additional fine-tuning rounds, failed
    Spot instances, larger future datasets, reviewer-
    requested re-analyses.                                $1,742

  TOTAL REQUESTED                                         $5,000

All GPU workloads use EC2 Spot instances (60-70% discount vs On-Demand).
Instances self-terminate after processing completes. S3 lifecycle
policies transition infrequently accessed data to Intelligent-Tiering.

2. PLAN FOR SHARING OUTCOMES

Open-Source Code

The complete pipeline is publicly available at
https://github.com/chaplinta/hm2p under the MIT licence. This includes:

  - Processing pipeline (Stages 0-6) with Snakemake orchestration
  - Docker containers for reproducible compute environments
  - EC2 launch scripts for cloud deployment
  - Streamlit frontend (53 pages) for data exploration and QC
  - 1500+ unit tests with 91%+ code coverage

Data Sharing

  - Processed datasets will be exported to NWB (Neurodata Without
    Borders) format using neuroconv and deposited on the DANDI archive
    (https://dandiarchive.org)
  - Raw data will be made available upon reasonable request

Publications

Results will be submitted for publication in a peer-reviewed journal
(target: eLife, Journal of Neuroscience, or Cell Reports). AWS support
will be acknowledged in all publications.

Methodological Contributions

  - The pipeline demonstrates a reproducible, cloud-first approach to
    freely-moving two-photon calcium imaging analysis that other labs
    can adapt
  - Comparison of multiple calcium event detection methods (V&H
    percentile, SD-threshold, CASCADE) at low frame rates (~10 Hz)
    provides practical guidance for the field


3. FUTURE AWS USE

Continued Research

The lab plans to continue using AWS for:

  - Processing additional recording sessions (new animal cohorts with
    optogenetic manipulation of Penk+ cells)
  - Running CEBRA and NEMOS analyses that benefit from GPU acceleration
  - Hosting the Streamlit dashboard for collaborator access

Broader Community

  - The open-source pipeline and Docker containers will enable other
    neuroscience labs to deploy similar analyses on AWS without building
    infrastructure from scratch
  - The pipeline architecture (Snakemake + S3 + EC2 Spot) serves as a
    template for cloud-based neuroscience workflows

Sustainability

After the credit period, ongoing costs are estimated at ~$15/month
(primarily S3 storage). This is sustainable from standard research
funds. GPU compute is needed only for periodic re-processing and is a
negligible ongoing cost with Spot pricing.
